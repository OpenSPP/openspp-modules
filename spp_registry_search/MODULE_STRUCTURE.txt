FEATURES:
=========
1. Configurable search fields for res.partner
2. Dynamic field filtering by registrant type (Individual/Group)
3. Target type support (Individual/Group/Both)
4. Full-width modern search interface
5. Type-aware search strategies
6. Always filters by is_registrant=True
7. Comprehensive test coverage

MENU LOCATIONS:
===============
User Interface:
  Registry → Registry Search

Admin Configuration:
  Settings → Administration → Registry Search Fields

API USAGE:
==========
Python:
  # Get searchable fields
  fields = env['res.partner'].get_searchable_fields('individual')
  
  # Search by field
  results = env['res.partner'].search_by_field('name', 'John', is_group=False)

JavaScript:
  // Load fields
  await this.orm.call('res.partner', 'get_searchable_fields', ['individual'])
  
  // Search
  await this.orm.call('res.partner', 'search_by_field', [fieldName, searchValue, isGroup])
